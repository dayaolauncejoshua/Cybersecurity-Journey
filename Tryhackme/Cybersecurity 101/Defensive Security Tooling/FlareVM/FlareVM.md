# FlareVM

    A Windows-based environment designed for malware analysis and reverse engineering. It comes with many preinstalled tools that helps investigate suspicious file safely.

    Uses to analyze suspicious Windows executables, malware, scripts, and documents. 

    Equivalent of REMnux.

### What can FlareVM do

    Static analysis: Examine a suspicious file without executing it.
    Dynamic analysis: Observe what a file does when executed in a controlled environment.
    Reverse engineering: Investigate how a program works by examining its code or instructions.
    Debugging: Step through a program to understand its behavior.
    String and file analysis: Extract readable text, identify file types, and inspect suspicious content.
