# CyberChef Interface

    CyberChef consists of four areas. Each consists of different components or features.

    These are the following areas:
    1. Operations
    2. Recipe
    3. Input
    4. Output

### The Operations Area

    Contains CyberChef's available tools. Operations are categorized, and you can use the search bar to find a specific operation. Hovering over an operation may show a description or example.

    Common Operations

    1. From Morse Code - Converts Morse code into letters and numbers. 
    Example: - .... .-. . .- - ... → THREATS

    2. URL Encode - Converts special characters into percent-encoded representations used in URLs.
    Example: https://example.com → https%3A%2F%2Fexample%2Ecom

    3. To Base64 - Encodes data into Base64 text.
    Example: This is fun! → VGhpcyBpcyBmdW4h

    4. To Hex - Converts data into hexadecimal byte values.
    Example: Hi → 48 69

    5. To Decimal - Converts data into decimal values.
    Example: Hi → 72 105

    6. ROT13 - Replaces each letter with the letter 13 positions away in the alphabet
    Example: HELLO → URYYB

### Differences 

    Encoding: Changes how data is represented
    Decoding: Reverses an encoding to recover original representation
    ROT13: A simple letter-substitution cipher, often used for obfuscation rather than secure encryption
    Morse code: Represents letters and numbers using dots and dashes
