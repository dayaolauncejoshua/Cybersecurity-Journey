# CyberChef: The Basics

    Is a web based tool that performs various data operations directly in your browser. It provides many tools for transforming, decoding, encoding, and encrypting information.

### Common Operations

    Base64: Encodes or decodes data into different representation
    XOR: Performs a bitwise operation using a key; commonly encountered in data obfuscation.
    AES: Encrypts or decrypts data using a secret key.
    RSA: Performs public-key cryptographic operations, including encryption and decryption.

### Recipes

    A sequence of operations that CyberChef executes in order. The output of one operation becomes the input to the next.

    Example:

    1. Input: SGVsds---
    2. Operation: From Base64
    3. Output: Hello

### Relevance to Cybersecurity

    Security analysts use CyberChef to decode suspicious strings, examine encoded data in logs, transform malware indicators, and analyze data encountered during investigations.
