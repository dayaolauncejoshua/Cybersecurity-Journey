**Security Operations Center (SOC)**

    Modern organizations store sensitive information in networks, computers, servers, and cloud systems. Attackers constantly look for vulnerabilities to steal, modify, or disrupt this information.

**What is a SOC?**

    A SOC is a dedicated team/facility responsible for continuously monitoring an organization's systems, detecting suspicious or malicious activity, and responding to it.

    Organization's Systems
        ↓
      Logs
        ↓
    Security Tools
        ↓
    SOC Team
        ↓
    Monitor → Detect → Investigate → Respond

**The SOC mainly:**

    1. Monitors networks, endpoints, servers, and other systems
    2. Detects suspicious activity and security threats
    3. Investigates alerts and incidents
    4. Responds to threats to reduce damage
    5. Documents security incidents

    Monitor → Triage → Investigate → Respond → Document
