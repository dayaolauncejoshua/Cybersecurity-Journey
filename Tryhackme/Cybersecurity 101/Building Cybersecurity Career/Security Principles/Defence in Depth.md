# Defense in Depth

    It is a security strategy that uses multiple security layers to protect systems, networks, and data. It is commonly called layered security approach.

### Examples

    Several security layers a company may use:

    1. Firewall - Filters inbound and outbound network traffic based on predefined rules.
    2. Antivirus/EDR - Detects and responds to malicious activity on endpoints.
    3. Multi-factor authentication - Adds another layer to login security.
    4. Access controls - Restrict access to authorized users.
    5. SIEM - Collects and analyzes logs to detect suspicious activity.
    6. Backups - Help restore data after incidents such as ransomware.

    Each layer serves different purposes, but when together, they reduce the chance of security failure.

    This is important because it prevents attacks, detect attacks, limits damage, and support recovery
