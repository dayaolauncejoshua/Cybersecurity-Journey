**What is Wireshark?**
    - is a packet analyser tool used for investigating live traffic over a network and inspecting packet captures (PCAP). It is one of the most commonly used packet analysis tool.
    - Packet Capture (PCAP) is a file containing captured network packets. Useful for investigating malware communication, suspicious connections, data exfiltration, and network attacks.
    - It allows you to see packets traveling across a network and examine details such as:
        - Source and destination IP addresses
        - Protocols used (TCP, UDP, HTTP, DNS, etc.)
        - Port numbers
        - Packet contents (if not encrypted)
        - Network errors or suspicious activity
