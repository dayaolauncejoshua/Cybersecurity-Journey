**Linux Shells**

    - A shell is a program that allows you to interact with the operating system by entering commands. Different shells provide different features and user experiences.

**Bourne Again Shell (Bash)**
    - the most widely used shells in Linux and is the default shell on many Linux distributions.
    - supports command execution and scripting
**Friendly Interactive Shell (Fish)**
    - focuses on user-friendly and beginner-friendly.
    - Autosuggestions and spell/error assistance
    - makes command lines easier and more interactive
**Z Shell (Zsh)**
    - modern and highly customizable shell.
    - Advanced tab completion
    - Supports scripting
    - Autosuggestions and spelling correction
    - Command history
    - Extensive customization

**Shell Scripting**
    - it is a file containing a set of commands executed automatically. Instead of repeating the commands one by one, you can place them inside a script then it will run the commands in order.
    - It is mainly used for automation.
        - Repetitive tasks, save time, less manual work, consitent task performance.
**Creating Bash Script**
    - for Bash script, the common extension is .sh. eg. myscript.sh
    - You can create and edit in a file using text editor nano. eg. nano myscript.sh
    - Every script should start from shebang "#!" #!/bin/bash
