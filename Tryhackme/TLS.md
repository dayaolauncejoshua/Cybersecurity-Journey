**Transport Layer Security (TLS)**
    - is a cryptographic protocol that provides secure communication between a client and a server over an untrusted network, such as the Internet.
    - TLS mainly provides:
        1. Confidentiality - others cannot easily read the data
        2. Integrity - cannot modify or tamper data without detection
        3. Authentication - certificates can help verify the indentity of the server

**SSL vs TSL**
    - older protocol designed for secure communication
    - TSL was developed as its successor with an improved security

**Key idea**
    - Original protocols use the same functions. TLS adds a security to the communication

**TLS Certificates**
    - helps prove the identity of the server.

**Important terms**
    - CSR (Certificate Signing Request) → A request created when applying for a digital certificate.
    - CA (Certificate Authority) → A trusted organization/entity that validates and signs certificates.
    - TLS Certificate → A digital certificate used to help verify the identity of a server or other entity.
    
    - TLS is important because it protects sensitive information from being read or modified while traveling across networks.
