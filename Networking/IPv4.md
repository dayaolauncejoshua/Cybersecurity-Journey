Topic: IPv4

What is IPv4?
- IPv4 is a logical address that identifies a host/device in a network. Each host/device in a network has a different IPv4. This enables a host to be able to communicate with other hosts/devices on the Internet.
- It must be properly configured and unique around the world, for remote communication.
- It is a 32-bit address divided into four 8-bytes(octets).

IPv4 Address Structure:
- It is made up of two parts, the network and the host.
- 192.168.1.1
- 192.168.1 = Network component - First 3 octets
- 1 = Host component - Last octet
- If a host has a different network portion and not configured on the same network, it would not be able to communicate with other devices one the same network without the use of routing.

Purpose of Subnet Mask:
- to identify which network a host belongs to.
