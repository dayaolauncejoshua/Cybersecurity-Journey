Topic: Communication Protocol

What I learned:
- Protocols are used in any computer for communication.
- It is a set of rules required for computers to communicate properly across the network.
- HTTP, HTTPS, DHCP, DNS, FTP, etc.

Why it matters in Cybersecurity:
- Protocols define how data travels accross the network. This is where attackers make their attacks. They find weakness in these protocols.
- Examples:
  - HTTP = Data is unencrypted, easier for attackers to intercept.
  - HTTPS = Encrypts data which makes harder for attackers to eavesdrop.
  - DNS = Domain Name System can be used for phishing methods or spoofing.
