Topic: Unicast, Broadcast, Multicast

Unicast:
- It is a one on one communication. A host sending a packet to a single device.
- the packet has a unicast address that is intendedly sent to only one receiver.

Broadcast:
- Is a communication where the host sends the packet to all devices on the same network expect the incoming port.

Multicast:
- Is a communication where the host sends a packet to a selected group of device in a muticast group. Only the members on a multicast group can process the packet.

A source address can only be one, regardless if it is a unicast, broadcast or a multicast.
