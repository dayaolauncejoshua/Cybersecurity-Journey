Topic: Network Segmentation

- One problem in broadcast domains is when we have large broadcast domain where it connects hundreds of hosts that could generate excessive traffic which results to a slow network connection and slows devices due to large traffics to process.
- Solution:
  - Reduce the size of the network to create smaller broadcast domains in a process called subnetting.


Why Network Segmentation Important in Security:
- This limits the spread of attacks
- It can add security policies where or which subnets can only communicate or which are not allowed.
