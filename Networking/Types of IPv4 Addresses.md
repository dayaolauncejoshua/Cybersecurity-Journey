Topic: Types of IPv4 Address

Public IP Address
- It is the unique logical address used on the Internet to identify your network.

Private IP Address
- Is a logical address in a network or a LAN

- When a device is to send a data outside its network, the packet will have a source private IP address and a public destination address.
- Before the packet can be forwarded, the source IP address has to be translated to a Public IP using Netword Address Translation.

Network Address Translation (NAT)
- It is the process where the router translates private IP addresses to public IP addresses vice versa.
