3. **Phishing Email Investigation**
Take a safe/sample phishing email.
Analyze headers, sender, URLs, domains, attachments.

Produce an analyst-style report.
Skills: phishing analysis, OSINT, threat analysis.

Capture normal traffic and suspicious-looking traffic in your lab.
Identify DNS, HTTP, TCP connections, IPs, ports, etc.
Explain what happened.
Skills: networking + packet analysis.

5. **Vulnerability Assessment Lab** 
Set up an intentionally vulnerable machine.

Identify vulnerabilities.
Research the CVEs.
Recommend remediation.
Skills: vulnerability management, Nmap, CVE research.

6. **Linux Security Hardening Project** 
Start with a Linux VM.
Audit users, permissions, SSH configuration, services, firewall, etc.
Harden the machine.
Document before → changes → after.
Skills: Linux administration + security.

7. **Windows Security Hardening Project** 
Create a Windows VM.
Configure users/groups, firewall, auditing, password policies, and other security controls.
